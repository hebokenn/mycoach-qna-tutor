# v1.1.0 完整服务流程补正

此前教学偏重排障，未完整呈现用户提供的《私教答疑流程话术》。本版将欢迎与称呼、感同身受、说明意图探需、复述确认、逐项同意后处理验证、完整收尾，贯穿20题攻略、备考、双向对练和记录评价。

- 每题核对型号、系统、发生时间/触发条件、顾客已试方法和结果；复述后等待确认。
- 每项操作前解释目的并征求同意，处理后问其他问题；收尾包括企微有效/无效反馈、支持App用途、满意评价、其他产品兴趣及按意愿转同事、关怀道别。
- 15分钟来自新增训练文件，正式考务以当期通知为准。
- 原稿保留并逐段提取，含原文空白编号；诊断/送修时长、备用机和资料保证作为待核实的门店示例。
- 记录评价增加流程查漏，原16项档位、权重和计分公式不变，不额外加减分。原人设、历史分数和201题练习保留。
- 支持App与送修准备的官方页面核对日期为2026-10-23。

验证包括原稿哈希及逐段保全、原量尺与100组数值夹具、全部人设引用、可迁移安装、ZIP CRC和文件哈希。场景与发布结果见[测试说明](testing.md)；应用内语音、电话和WorkBuddy导入不在文字试用证明范围。
