# 私教答疑 Skill v1.0.1

将20题攻略、顾客人设、历史案例、原始16项量尺和Apple官方参考资料整合为可安装技能：支持考试答疑、AI扮顾客/Coach的双向对练，以及对练记录的证据评价。

本版补齐Codex与WorkBuddy安装说明、可复制使用示例、8个文字场景及6张实际测试记录截图。场景覆盖一周备考、黑屏朗读、账户安全、储存空间、多轮顾客对练、摘要/片段评分及媒体缺失处理。

试用中修正两项行为：顾客遇到未知背景时自然保留未知；评分不因摘要缺少具体话术就推断表现差。B1/B2已针对修正复测，其他场景保留初测原文与版本。

- 23项自动检查通过，包含100组计分引擎对照输入。
- 8个场景共50项观察检查通过；完整记录与证据在仓库`docs/scenarios/`。
- 两个安装包验证ZIP CRC、逐文件SHA256和脱离原项目的脚本运行。

下载标准包用于Codex或兼容SKILL.md的宿主；WorkBuddy使用带`workbuddy`的包。下载后可用同页`SHA256SUMS`核对文件。

本仓库含授权内部学习资料，保持私有。WorkBuddy原生导入、电话、语音及视频观察尚未实测；截图为实际文字测试输出的浏览器报告页面，不是原生应用界面。知识资料快照为2026-10-22，正式考试规则需核对当期通知。
