# 19题深入讲解：学员视角检查

检查日期：2026-10-23。范围是第2至20题、77个讲解单元。第一题沿用此前认可的内容。这里记录当前作者按初学者视角进行的语义检查和实际页面检查，不能代替真人学员的学习实验，也不称为独立AI评测。

## 判断学员是否有足够的学习材料

每题必须支持五件事：能说清功能是什么；能把原因按先后讲出来；能向顾客用普通话解释；知道为什么做这项操作、怎样核对结果；能回答一种常见追问。77个单元各有功能、三步因果、益处、参考话术、操作与验证、追问回答和一道口头自测。77道口头自测不混入原有201道情境练习。

## 逐题走查

| 题目 | 学员应能回答的问题 | 本次补足的理解环节与带练方法 |
| --- | --- | --- |
| 屏幕黑点 | 为什么正常功能也会画出黑点？怎样与显示异常区分？ | 解释乘车时视觉与身体运动线索的差异；区分辅助触控、缩放和指针；截图是图像资料而非屏幕实物照片，不能单项确诊。再用菜单和开关对照验证。 |
| 充电发烫 | 电从哪里进来、为什么变成热？边充边玩为什么更严重？ | 补电能转换、传输与储能的损耗，以及计算/显示/通信的用电；无线充电另讲磁感应。解释产热与散热、温度保护和充电变慢，再给相近条件下减少负载的验证。 |
| 发热并黑屏 | 画面消失、声音继续，是不是同一个原因？ | 将温度管理、显示、语音和触控分开讲；按发生顺序判断共同诱因或并存。降温后分别确认显示、操作和温度，不用亮屏代替全部解决。 |
| 信号差 | 有信号格为什么仍不能打电话？飞行模式能做什么？ | 说明无线接入与运营商通话服务是多环节；重连不能创造覆盖或线路资格。补还原网络的具体影响，用原通话渠道和条件测试。 |
| 掉电快 | App占比、当前电量、最大容量和循环数分别是什么？ | 用统计窗口与实际活动解释占比，讲容量与负载共同影响续航；累计用电才形成循环。补弱覆盖下仍需搜索/维持连接的能耗，省电调整保留顾客需求。 |
| 微信删除后下载要密码 | 下载、解锁、微信登录究竟验证谁？ | 分清设备、Apple、微信及一次验证码；解释面容ID为何不代替所有密码；安装成功与聊天资料恢复分别核对。给受信任设备/号码与官方恢复入口。 |
| 陌生Apple账户 | 顶部已登录本人，为何更新App还问其他账户？ | 分清服务登录和历史购买归属；说明双重认证位置是网络线索。按提示服务核对，不由邮箱提示推定翻新或忽略安全请求。 |
| iPad要求旧设备密码 | 已登录账户，为什么还要旧设备批准？ | 先定义加密与访问权限，再用“资料上锁”解释批准新设备。核对系统指名的设备和凭据；不把旧设备提示当二手证据，不轻率重设加密资料。 |
| 出现陌生照片 | 同步、家人共享、共享图库、相簿有什么不同？ | 说明共用账户可能在看同一份更新图库，删除也会传播；家人共享空间不等于自动公开照片。给来源核对入口，先处理来源与副本，再处理内容。 |
| 看不到朋友位置 | 我分享给他，为什么仍看不到他？ | 用两个方向的授权解释关系；讲一次位置与实时共享、时长及来源设备，定义定位信息与联系人信息的不同。分别确认请求、同意和实际显示。 |
| Apple扣费 | 免费下载为何还扣费？删App为何仍续费？ | 解释程序获取、App内交易与订阅关系；取消、退款申请、批准、到账是不同过程。由本人对照收据和购买账户，再核对具体状态。 |
| 陌生电话不响 | 未知来电、专注、静音和屏蔽分别管什么？ | 讲规则作用范围、询问原因的流程和通话记录的局限；设置需匹配接快递等实际需求。用已存/未存、时段和通话方式相符的条件验证。 |
| 手表不提醒微信 | 为什么手机响而手表不响？红点是不是通知总开关？ | 明确手机解锁与手表接收状态的默认分配；把消息内容、系统通知、声音/触感、未读红点分开。先查手机来源，再按锁屏/手表解锁等条件测试。 |
| 黑屏但会读字 | 旁白和幕帘屏分别做什么？为什么点法变了？ | 解释显示与语音独立、先选中再激活；明确三指三下与同时缩放时四下的条件。亮屏和恢复普通点按分别核对，并教会日后自助恢复。 |
| 邮件收不到 | 网页能收为什么手机不能？推送、抓取、通知哪里不同？ | 解释客户端授权、IMAP/POP、服务器与本机资料；分清服务端到信、客户端获取、到达后提醒。补具体账户/抓取入口，移除前确认重要邮件保存位置。 |
| 联系人误删 | 为什么另一台也少了？恢复旧版本会影响什么？ | 同步不是任意历史备份；先查账户和列表。解释归档替换当前联系人集合，恢复前保留近期新增；给平板/电脑官方入口，最后核对重要联系人及完整范围。 |
| 储存空间满 | 运行内存、机身容量、iCloud能否互相替代？ | 用工作台、文件柜和云仓库说明用途；解释卸载/删除/只移图标的差异、优化照片与同步删除的差异。查看实际容量和资料可用性，不保证系统数据一键清空。 |
| Apple账户无法退出 | 灰色头像与退出受限为什么要分开查？ | 解释访问限制的权限作用；区分屏幕使用时间密码、设备密码及恢复账户。补实际入口和本人/家长管理关系，退出前说明资料与服务影响，延迟另走对应流程。 |
| 无法更改密码 | 为什么知道旧密码还要等？等完是否就改好了？ | 解释被他人同时取得手机与密码的风险；完整讲本人认证、等待、再次认证及完成更改。区分熟悉地点/始终、安全延迟/账户恢复/输错密码，关闭保护本身也受约束。 |

## 自查发现后已修正

1. **术语出现但没定义。** 补“加密”与开锁权限的通俗解释；把IMAP/POP、通知镜像、后台和空间类别放在各自用途里说明。
2. **有原因但缺中间环节。** 充电补损耗到热、热向外散出；边充边玩补计算/图形/屏幕/网络工作，避免“电池同时充放电”的误导。同步补编辑和删除如何传播，弱覆盖补连接活动仍需用电。
3. **操作指引过于泛。** 补购买账户、照片、通讯录、邮件抓取、订阅、屏幕使用时间和失窃设备保护的入口；版本变化给出实机核对方法，不要求所有菜单一致。
4. **一页四栏长文难读。** 改为选择一个单元完整阅读；问答与自测在同一单元。自测答案初始收起，翻到下一讲回到正文起点，避免留在上一讲底部。

## 目前能支持什么，还要补什么

文字材料已能支持逐步理解、向顾客解释和按结果核对，适合作为备考教材和对练依据。不能仅凭作者自查就断言所有初学者已经学会。

要进一步确认“看完就能上手”，建议补三组实际设备演示：旁白/幕帘屏/缩放的手势与反馈；iPhone锁屏和Watch解锁时的通知对照；照片/通讯录同步与恢复前后变化。账户、邮件和安全设置也需要用当前考试常用机型拍清菜单。这些要用对应实机录制，示意画面不能冒充成功操作。

随后请未参与编写的学员随机抽题，先不看答案解释原因，再带练一次，记录卡在哪个概念或入口。这才能确定真人仍学不会的具体位置。本次没有把尚未发生的实机教学或真人试学算为通过。
