# 私教答疑原始评分量尺

原始Excel随包保留：[私教答疑量尺](../assets/private-qna-standard.xlsx)。以下16项标准逐字取自该Excel；档位、细项权重与网站结构化量尺核对。网站中直引号、空格和少量句末句号的排版差异保存在JSON的websiteStandard，不改写原Excel。

| 维度 | 占总分 | 维度说明 |
| --- | --- | --- |
| 解决方案落地性 | 30% | 排障逻辑清晰有条理，诊断准确，方案真实有效可行，能给出行之有效的替代方案。 |
| 知识准确专业性 | 35% | 产品知识与政策描述准确，复杂原理通俗化与场景化描述能力，与启发式价值，演示无误。 |
| 服务技巧 | 25% | 倾听不打断、冷静化解情绪、感同身受共情缓冲、结构化探询与复述确认焦点。 |
| 流程完整 | 10% | 标准化开场招呼、提问意图管理、核心痛点对齐、风险告知与隐私合规、状态反馈与服务收尾。 |

每项贡献=原始分/10×维度占总分权重×细项维度内权重/100。流程有=10、无=0；未观察留空不代入0。当前MyCoach模拟规则≥80为通过，正式考务以当期通知为准。

## 第1项：建立私教身份、展现私教温度

- 项目键：`qna-01`
- 阶段：热情欢迎 / 招呼顾客
- 维度：流程完整；维度内部权重5%；折合满分0.5分。
- 类型：流程有/无。

**原标准**

1.招呼顾客，做标准自我介绍【流程-有/无】

**有**

必须包含：礼貌问候 + 自我介绍 + 私教身份表明（如"您好，我是今天的私教 Coach…"）。

**无**

缺失自我介绍，仅机械询问"有什么问题"。

## 第2项：建立私教身份、展现私教温度

- 项目键：`qna-02`
- 阶段：热情欢迎 / 招呼顾客
- 维度：服务技巧；维度内部权重10%；折合满分2.5分。
- 类型：0–10分。

**原标准**

2.礼貌用语，自信大方，不使用生硬/压迫性词汇，展现出专业的教练温度。【感受-打分：0~10】

**0–4分**

语态生硬，压迫感强
使用生硬、命令或压迫性词汇，让顾客感到不适。

**5–7分**

语言平淡，偶有生硬
使用了基本礼貌用语，但沟通拘谨或说教感。

**8分**

表达礼貌，沟通自然
语言礼貌规范，表达自然得体。

**9–10分**

语态典雅，专业从容
展现出专业自信与教练温度，语言得体亲和。

## 第3项：情绪承接技能

- 项目键：`qna-03`
- 阶段：倾听、探索、确认问题 / 倾听顾客表示感同身受
- 维度：流程完整；维度内部权重15%；折合满分1.5分。
- 类型：流程有/无。

**原标准**

3.认真倾听，面对抱怨、指责或急躁时，控制情绪不急躁打断，不出现不耐烦，专业降温表达共情。【流程-有/无】

**有**

面对顾客的焦虑、抱怨或急躁时，全程不打断、不辩解、不急躁，有清晰的倾听与情绪降温动作。

**无**

在顾客陈述问题时强行打断、急于反驳或表现出不耐烦。

## 第4项：表达感同身受

- 项目键：`qna-04`
- 阶段：倾听、探索、确认问题 / 倾听顾客表示感同身受
- 维度：服务技巧；维度内部权重30%；折合满分7.5分。
- 类型：0–10分。

**原标准**

4.接纳顾客情绪真实流露，能运用“缓冲表达”展现共情与陪伴度，用合适语言表达感同身受，不尴尬。【感受-打分：0~10】

**0–4分**

忽略情绪，说教冷漠
完全忽略顾客的情绪表达，直接冷冰冰说教或尴尬。 或者出现换位思考过度，顺着顾客瞎猜硬件质量问题的场景。

**5–7分**

共情生硬，流于形式
尝试共情但话术生硬尴尬（如生硬复读"理解您"），缺乏真诚陪伴感。或者共情用词欠妥或缺乏专业中立性，主动对设备质量/硬件损坏做负面推测，人为引发或放大了顾客对产品品质的恐慌。

**8分**

理解接纳，适当缓冲
能自然表达理解与接纳，使用缓冲表达感同身受，给予心理陪伴。（如"确实，这放在谁身上都会很着急，我们一步步来帮您解决"）

**9–10分**

共情自然，极具陪伴
共情自然贴切，提供出色的情绪价值，让顾客感到被倾听与尊重。

## 第5项：结构化探询

- 项目键：`qna-05`
- 阶段：倾听、探索、确认问题 / 探询与确认问题
- 维度：流程完整；维度内部权重15%；折合满分1.5分。
- 类型：流程有/无。

**原标准**

5.说明提问意图，管理问题预期【流程-有/无】

**有**

在排查提问前，主动告知提问目的（如"为了帮您快速锁定原因，我先向您了解几个使用细节…"）。

**无**

突击式提问，未做意图管理，让顾客产生被"盘问"的压迫感。

## 第6项：结构化探询

- 项目键：`qna-06`
- 阶段：倾听、探索、确认问题 / 探询与确认问题
- 维度：服务技巧；维度内部权重40%；折合满分10分。
- 类型：0–10分。

**原标准**

6.探询思路清晰，指向明确、通俗易懂、方便回答。遵循“倾听-确认-再提问”逻辑，避免连珠炮式反问顾客。【感受-打分：0~10】

**0–4分**

连珠炮提问，指向混乱
探询思路混乱，指向不明；连续抛出多个问题逼问顾客。

**5–7分**

提问偏多，缺乏节奏
探询缺乏逻辑递进，问题多且绕弯，未有效预留回答时间，让顾客感到疲惫。

**8分**

思路清晰，按步提问
探询思路基本清晰，有递进收窄问题范围的意识，也能按"倾听-确认-再提问"逻辑推进。（允许提问话术偏向标准排查套路、偶有连续发问，但节奏平稳，成功锁定了故障焦点。）

**9–10分**

逻辑递进，高效启发
提问极具有递进感与启发性，引导自然通俗有效率，且迅速收窄故障范围。

## 第7项：确认核心痛点

- 项目键：`qna-07`
- 阶段：倾听、探索、确认问题 / 探询与确认问题
- 维度：流程完整；维度内部权重20%；折合满分2分。
- 类型：流程有/无。

**原标准**

7. 与顾客共同对齐并确认要解决的核心问题。【流程-有/无】

**有**

通过"复述+确认"的方式，口头与顾客共同锁定本次答疑必须解决的核心问题并达成共识。

**无**

未与顾客对齐问题焦点，凭借主观臆断直接开始排查。

## 第8项：确认核心痛点

- 项目键：`qna-08`
- 阶段：倾听、探索、确认问题 / 探询与确认问题
- 维度：服务技巧；维度内部权重20%；折合满分5分。
- 类型：0–10分。

**原标准**

8.定位问题清晰不拖沓，能使用“复述+确认”的方式与顾客共同对齐要解决的核心痛点【感受-打分：0~10】

**0–4分**

指责顾客，主观断定
定位问题指责顾客；或者未经确认就主观断定故障原因。

**5–7分**

确认模糊，对齐不足
探询后未有效复述，或者机械复述，实际与顾客对齐的问题焦点存在偏差。

**8分**

复述确认，焦点对齐
定位清晰不指责，复述得体，能使用"复述+确认"与顾客达成解决共识。

**9–10分**

精准定位，共识清晰
精准提炼痛点，复述很清晰得体，与顾客达成高度解决共识。

## 第9项：预期管理与排障逻辑

- 项目键：`qna-09`
- 阶段：提供帮助 / 解决方案
- 维度：流程完整；维度内部权重15%；折合满分1.5分。
- 类型：流程有/无。

**原标准**

9. 有排障意识，在执行可能引起变化的操作（如重置/升级）前，主动进行预期管理（明确告知潜在风险或结果）。或在排障中提醒顾客保护密码等隐私数据，合规操作。【流程-有/无】

**有**

涉及可能导致数据变化的动作（抹掉/升级/重置/退出账号）前明确做风险告知与备份提示；涉及输密码时主动避让提醒。

**无**

涉及关键重置/抹掉时完全不提醒备份风险；或直接窥视顾客输入密码。

## 第10项：提供解决方案

- 项目键：`qna-10`
- 阶段：提供帮助 / 解决方案
- 维度：解决方案落地性；维度内部权重40%；折合满分12分。
- 类型：0–10分。

**原标准**

10. 有实质性解决方案提供，另外若受限于政策/硬件时，能主动提供可行性替代方案。【感受-打分：0~10】

**0–4分**

拒绝提供，生硬甩锅
无明确解决方案提供，且受限时直接拒绝；或盲目推脱给 400 或售后诊断。

**5–7分**

方案生硬，缺乏解释
有解决方案，但不清晰不落地；或者受限时提供了替代方案但解释模糊，后续步骤交代不清。

**8分**

方案可行，交代步骤
能给实质性解决方案，且有落地实操性；受限时能主动给可行替代方案，且能清楚描述方案。（允许替代路径偏常规、防范建议相对基础，但方案切实可行、后续步骤交代清楚，顾客能顺利执行）。

**9–10分**

方案完备，导向清晰
替代方案周密贴切，后续流程交代非常清晰，化被动为主动。如在受限情况下主动提供 1~2 种极具可行性的替代路径；不仅交代清晰后续解决步骤，更主动提供长效预防建议或规避二次踩坑方案。

## 第11项：提供解决方案

- 项目键：`qna-11`
- 阶段：提供帮助 / 解决方案
- 维度：解决方案落地性；维度内部权重60%；折合满分18分。
- 类型：0–10分。

**原标准**

11. 排障逻辑严密无疏漏，解决方案合理能落地。【感受-打分：0~10】

**0–4分**

逻辑混乱，盲目排查
排障思路混乱，试错盲目；未解决问题就终止排查。

**5–7分**

逻辑脱节，存在疏漏
排障主线大致对，但步骤存在明显跳跃、无效试错多，或仅治标未治本（缺失长效预防导致二次踩坑）。同时未做排障预期管理（未说明操作意图与预期目的，直接下达动作指令，导致顾客不明所以、产生盲目跟操作的被动感。）

**8分**

逻辑清晰，方案落地
排障主线思路正确，解决方案合理可行，能帮顾客根本解决问题（允许个别小步骤顺序颠倒，但不影响最终解决）；排障次序规范，关键排障动作前能先告知操作意图（先交待目的，再指导操作）。遵循"告知排障意图与预期 ➡️ 引导执行操作 ➡️ 确认状态反馈"的正向闭环。

**9–10分**

逻辑严密，高效排障
排障逻辑严丝合缝，排障次序清晰、导向与掌控力极佳，操作意图交代极其自然明了，诊断迅速精准，方案一针见血，长效预防（如防二次误触）周密。

## 第12项：知识与概念

- 项目键：`qna-12`
- 阶段：提供帮助 / 解决方案
- 维度：知识准确专业性；维度内部权重40%；折合满分14分。
- 类型：0–10分。

**原标准**

12. 涉及的产品知识、最新政策（如 NPI）运用正确，无张冠李戴、无凭空猜测（“好像、可能不行”）。【感受-0~10】

**0–4分**

概念错误，凭空猜测
产品知识/政策出现严重错误；凭空猜测（"好像不行"）。

**5–7分**

概念模糊，不够自信
对知识点表述含糊不自信；个别次要概念表述不准确。

**8分**

知识准确，无原则错误
核心产品知识与政策（如 NPI）讲解、运用准确无原则性错误。(允许偶有口误，或极冷门参数短暂查验)

**9–10分**

严谨精通，说服力强
知识掌握扎实严谨，政策熟悉，表达自信具极强说服力。

## 第13项：知识与概念

- 项目键：`qna-13`
- 阶段：提供帮助 / 解决方案
- 维度：知识准确专业性；维度内部权重40%；折合满分14分。
- 类型：0–10分。

**原标准**

13. 能将复杂机制通俗化。能够运用“场景化比喻”向用户清晰讲解底层逻辑，功能使用好处传递清晰，信服力强。涉及到演示，演示清晰准确。【感受-0~10】

**0–4分**

充斥术语，讲解晦涩
过度使用技术术语，讲解晦涩混乱，无法传达益处与底层逻辑

**5–7分**

转化一般，偏说明书
尝试解释底层逻辑但偏向"读说明书"，缺乏贴切场景；或者缺乏前置主动性，未主动向顾客解释故障出现的底层原因与功能设计初衷，经顾客追问后才被动应答解释。

**8分**

通俗易懂，举例实用
能用通俗易懂语言讲清底层逻辑，能用常见生活场景举例说明益处。且在指导顾客操作前或同步时，能主动向顾客解释底层逻辑与功能益处/设计初衷（如为什么会黑屏发声/盲人幕帘屏/这是无障碍保护模式等）。（允许比喻偏基础、益处说明偏大众化，但讲清了原理与保护初衷，顾客能听懂）。

**9–10分**

场景比喻，深入浅出
场景化比喻精准生动，将复杂机制讲得透彻明了，信服力极强。主动引领顾客了解底层意识强，给顾客带来极大的启发感与安全感。

## 第14项：操作与反馈

- 项目键：`qna-14`
- 阶段：提供帮助 / 解决方案
- 维度：流程完整；维度内部权重15%；折合满分1.5分。
- 类型：流程有/无。

**原标准**

14.有操作和演示引导顾客，并适时关注顾客的操作，在顾客的关键操作中给予状态反馈（如了解顾客目前在什么进度）。【流程-有/无】

**有**

在排障和演示中，实时跟进并确认顾客的当前进度（如"您现在屏幕显示的是哪一步？"）。

**无**

私教自己埋头操作或盲目下达指令，完全不确认顾客的跟随状态。

## 第15项：操作与反馈

- 项目键：`qna-15`
- 阶段：提供帮助 / 解决方案
- 维度：知识准确专业性；维度内部权重20%；折合满分7分。
- 类型：0–10分。

**原标准**

15. 操作演示清晰准确，关注顾客操作的节奏【感受-0~10】

**0–4分**

演示含糊，节奏失控
操作演示含糊混乱，完全无视顾客的跟进节奏。

**5–7分**

演示偏快，关注欠佳
演示步骤部分清晰，节奏偏快，对顾客的跟随关注不够。

**8分**

演示清晰，关注节奏
演示步骤基本清楚，节奏适中，能关注顾客的操作节奏并给予反馈。(允许中间有短暂停顿，不影响整体跟随)

**9–10分**

演示精准，同频互动
操作演示赏心悦目，精准掌控引导节奏，与顾客实现极佳同频。

## 第16项：推荐资源，结束服务

- 项目键：`qna-16`
- 阶段：邀请顾客再次惠顾 / 服务收尾
- 维度：流程完整；维度内部权重15%；折合满分1.5分。
- 类型：流程有/无。

**原标准**

16.确认问题解决，如有其他资源可推荐。邀请顾客对服务评价、并礼貌结束服务。【流程-有/无】

**有**

口头确认顾客问题是否已彻底解决，按需推荐支持资源/Apple Support，礼貌道别闭环。

**无**

问题解决后直接冷场或草草结束，未口头确认顾客是否满意/是否还有其他疑问。
