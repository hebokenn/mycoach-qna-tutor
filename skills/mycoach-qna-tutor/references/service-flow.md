# 私教答疑完整服务流程

将下面六个环节贯穿完整对练、Coach示范和备考。只问单个技术知识点时直接回答；用户要练中间片段时按指定范围练，复盘注明范围。排障地图只展开第五环节，不能代替整轮服务。

## 1. 热情欢迎

- 礼貌问候，自我介绍并说明私教身份。
- 询问顾客怎么称呼；已主动告知时沿用称呼，不重复盘问。
- 听主诉，结合实际情境自然寒暄；天气、出行等信息未知时不编造。

话术示范：“您好，我是今天的私教Coach。请问怎么称呼您？您今天遇到了什么问题？”

对照原量尺第1、2项；这是教学映射，不新增评分条件。

## 2. 感同身受

- 认同：复述问题和对顾客的实际影响；顾客已说影响时沿用原话。
- 共鸣：举自己、朋友或以往顾客真实发生的类似情况，也可用明确的情境类比；不编造经历，不因相似就认定原因相同。AI演示时不得虚构自己的真实经历。
- 保证尽力帮助，不保证一定解决，也不因相似案例直接下诊断。

话术示范：“您说这个情况影响了……，也让您担心……。我理解这种顾虑。我会尽力陪您查清原因、找到可行的办法。”

对照原量尺第3、4项；这是教学映射，不新增评分条件。

## 3. 说明意图并探需

- 先说明提问是为了更快定位问题，并征求配合；每轮自然问一两个问题。
- 每个题目都核对设备型号和系统版本；顾客记不清时先解释目的，再协助查看。
- 询问何时开始、发生频率和触发条件，尽量还原场景及实际影响。
- 询问顾客已经尝试过什么、各自结果如何，避免让顾客盲目重复。

话术示范：“为了更快帮您定位原因，我想确认几个细节，可以吗？您用的是什么型号、系统版本？”

对照原量尺第5、6项；这是教学映射，不新增评分条件。

## 4. 探需总结并确认

- 串起型号、系统、发生时间、触发条件、现象、影响、已试方法和期望。
- 用已知信息复述并等顾客确认或纠正；未知项保留待核，不自行补齐。

话术示范：“我确认一下：您的设备是……，系统……，在……情况下遇到……，已尝试……但结果……；您这次最想解决……，这样理解对吗？”

对照原量尺第7、8项；这是教学映射，不新增评分条件。

## 5. 解释、操作、验证

- 先解释有证据支持的可能原因；未验证时保留假设，不把功能相似当确诊。
- 每一项操作前说清目的、预期变化和必要影响，并征求同意；顾客亲手做，逐步等反馈。
- 能现场解决就带着操作并验证最初的困扰；不能现场解决则给改善措施或协助售后诊断。
- 当前问题处理后询问是否还有其他需要帮助的问题；未解决时也不能假装已解决。

话术示范：“这一步是为了确认……，可能会改变……。我带您操作，可以吗？做完后请告诉我现在显示什么，我们再验证……。”

对照原量尺第9、10、11、12、13、14、15项；这是教学映射，不新增评分条件。

## 6. 完整收尾

- 建立企业微信等实际可用的后续联系；回去验证后，无论有效或无效都可反馈，明确要反馈什么。
- 推荐Apple支持App，说明使用答疑和预约服务的用途；按实际地区和设备可用情况引导。
- 礼貌邀请满意评价，不强迫好评。
- 询问是否对其他产品感兴趣；有兴趣再转同事介绍，没兴趣尊重选择，不耽误时间。
- 结合真实情况作出行关怀、道别；需要售后时经顾客同意，通过企微提供已核实的预约入口。

话术示范：“回去试过后，有效或仍有问题都可以通过企业微信反馈。Apple支持App也能查使用帮助和预约服务。对今天服务满意的话欢迎评价。您还对其他产品感兴趣吗？”

对照原量尺第16项；这是教学映射，不新增评分条件。

## 售后诊断分支

有明显异常、合理排查仍未恢复，或顾客仍担心设备质量时。存在安全异常先停止危险操作并获得专业服务。

- 先接住质量顾虑，汇总已确认与待检测部分；不顺着猜硬件，也不无依据保证没有问题。
- 说明为什么需要诊断、在哪里、如何预约及所需准备；在实际确认后说明陪同、预计时间、费用及用机安排。
- 原文的诊断10至20分钟、送修10个工作日以内、备用机及资料不会丢失属于该文件的门店示例，不能直接视为Apple统一政策或无条件承诺。
- 核实本店服务后再给具体安排；涉及资料操作先确认备份，密码由本人输入，不保证零数据丢失。

可用示范：“目前已确认……，还不能确定……。我可以帮您核实店内诊断和预约安排；预计时间、备用机及资料准备，以本次实际确认结果为准。”

原话中的门店时间与备用机安排应保留为来源示例，技术或服务保证须另核实；共鸣段落也不意味着“别人是设置问题，所以本顾客一定相同”。

## 模式中的使用方式

- AI扮顾客：只给主诉开场，留给学员完成欢迎和完整探需；不主动提示流程，也不为补全流程而编造称呼、型号、系统或历史结果。未被问到的历史背景继续隐藏。
- AI扮Coach：用户已提供的信息直接承接，补尚缺环节；先问称呼、再自然探询，不反复索取已知信息。共鸣可说明为教学情境，不能虚构真实经历。
- 完整示范稿：按六阶段展开，写出顾客配合与纠正的位置；任何新增结果标为模拟。
- 记录评价：在原16项计分表外增加流程查漏，标出已完成、完整记录未做、记录未覆盖或无法观察；附原话位置。流程查漏不与原量尺重复扣分。

流程用于训练和查漏，不另设分数、权重、加分项或一票否决；仍按原16项量尺及档位计分。
